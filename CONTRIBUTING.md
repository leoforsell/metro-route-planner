# Arbetsmetod

1. Välj nästa issue i beroendeordning och bryt ned den till pass på cirka 1–3 timmar.
2. Läs teori, skriv ett eget exempel och prova själv. Be AI om ledtrådar före färdig kod.
3. Skapa en branch från aktuell main; branchförslag finns i varje issue.
4. Gör små commits, exempelvis `feat: add sale totals` eller `test: cover empty graph`.
5. Öppna PR mot main med `Closes #N`, motivering, testresultat och lärdom.
6. Granska kod och diff. Kör relevanta tester, rätta problem och slå samman PR när kriterierna är uppfyllda.

## Klart betyder

- Acceptanskriterier uppfyllda och relevanta tester gröna.
- README beskriver det som faktiskt fungerar.
- Koden är granskad och du kan förklara den med egna ord.
- Demonstrera beteendet och stäng sedan aktuell issue.

## Veckouppföljning

Välj 2–3 lagom stora uppgifter eller deluppgifter. Följ upp vad som fungerar, vilket test som visar det, vad du kan förklara själv och nästa minsta steg. Arbeta huvudsakligen med ett projekt åt gången.
